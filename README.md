# Compositional Image Retrieval on CelebA — Deep Learning 2026

Composed image retrieval with CLIP: given a reference face image and a set of signed
attribute constraints (e.g. `+Eyeglasses, -Smiling`), retrieve the images from the
CelebA test split that keep the identity of the reference while satisfying every
constraint. Three methods of increasing sophistication are implemented and compared:
zero-shot latent arithmetic (baseline), visual attribute directions (training-free),
and a gated cross-attention fusion module trained with InfoNCE (main contribution).

## Project structure

- `Project.ipynb` — **the main deliverable**: code + report (three methods, official
  benchmark, statistical analysis with bootstrap CIs, custom queries, qualitative
  success/failure cases)
- `Project_Skeleton.ipynb` — course-provided starter notebook (kept for reference)
- `METHOD.md` — Level-3 design notes: every implementation choice explained and
  mapped to its source of inspiration
- `RUNNING.md` — how to run the project on Google Colab and on an Azure GPU VM
  (setup, cache portability, troubleshooting)
- `database/` — `celeba_evaluation.json` (official benchmark); when running locally,
  the dataset zip (git-ignored) and the `.pt` caches generated by the notebook also
  live here
- `documentation/` — assignment PDF and reference papers
- `CLAUDE.md`, `CONTEXT.md`, `.claudeignore` — AI-assistant context files

## Getting started

See `RUNNING.md` for the full guide. In short:

- **Colab** (official environment): put `celeba.zip` and `celeba_evaluation.json` in
  `MyDrive/datasets/`, open `Project.ipynb`, select a GPU runtime, *Run all*.
- **VM / local**: copy `celeba.zip` into `database/`, launch Jupyter from the repo
  root, run the notebook top to bottom. Set `SMOKE_TEST = True` in the config cell
  for a fast first shakedown.
